# Sää

Ad-free weather app: Finnish Meteorological Institute (Ilmatieteen laitos) forecast with expandable daily → hourly view, rain radar and a 2 h rain nowcast.

Open with your location once: `https://reijar.github.io/saa/?lat=60.45&lon=22.27` — it's remembered on the device. Default is central Helsinki.

Data: [FMI open data](https://en.ilmatieteenlaitos.fi/open-data) (CC BY 4.0), [MET Norway](https://api.met.no/) nowcast. Icons: [metno/weathericons](https://github.com/metno/weathericons) (MIT). Map: Esri.
